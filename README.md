# 🌙 SharedPreference Dark Mode App

A modern Android app built with **Kotlin** and **ConstraintLayout** that demonstrates how to use **SharedPreferences** to store user data, manage app settings, and toggle **Dark/Light Mode** with real-time theme switching.

## Project Overview

This app allows users to save their **Name** and **Age**, toggle **Notifications**, and switch between **Dark and Light Mode**. All settings are stored using **SharedPreferences**, so they persist even after the app is closed or restarted.  

It is built to demonstrate best practices for handling persistent data and dynamic theme changes in Android.

---

## ✨ Features

- 📝 Save and display user **Name** and **Age**  
- 🔔 Toggle **Notification On/Off**  
- 🌗 Switch between **Dark and Light Mode** instantly  
- 💾 Data saved persistently with **SharedPreferences**  
- 🧹 Clear all saved data with one tap  
- ⚡ Built with **Kotlin**, **View Binding**, and **ConstraintLayout**

## 📱 Usage

1. Launch the app.  
2. Enter **Name** and **Age** in TextInputLayouts.  
3. Toggle **Notifications** and **Dark/Light Mode** switches.  
4. Press **Save** to store all data in SharedPreferences.  
5. All settings and theme persist across app restarts.  
6. Press **Clear** to reset all saved preferences.  
7. Toast messages provide feedback for Save/Clear actions.
